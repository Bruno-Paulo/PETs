# 🧠 The Technical Reference Guide

The **Technical Reference Guide** is your in-depth companion for understanding the theory, architecture and limitations 
of each Privacy Enhancing Technology (PET). It's designed for engineers, researchers and decision-makers who need to go
beyond practical tutorials and delve into the technical details.

---

## 🧠 What's inside?

Each PET entry includes:

- **🔍 Definition & Background** - Understand the core principles and origins.
- **📈 Applications** - See how PETs are used in different areas with real-world examples.
- **⚖️ Trade-offs** - Learn about the trade-offs between scalability, performance and privacy.
- **🧪Algorithms & Protocols** - Dive into technical primitives and core workflows.
- **⚠️ Limitations** - Consider practical risks and deployment challenges.

The guide is **modular and extensible**, allowing PETs to be compared side-by-side or added over time.

## ✅ Available PETs:

| PET                                                                    | Description                                                                                                                     |
|------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------|
| [Synthetic Data (SD)](Synthetic%20Data.md)                               | Generates artificial datasets that preserve the patterns and statistical properties of the original data.                       |
| [Differential Privacy (DP)](Differential%20Privacy.md)                   | Adds noise to data to ensure privacy while preserving overall data utility.                                                     |
| [Distributed Learning (DL)](Distributed%20Learning.md)                   | Enables machine learning models to be trained on multiple sensitive data sources without disclosure to parties.                 |
| [Homomorphic Encryption (HE)](Homomorphic%20Encryption.md)               | Allows computations to be performed on encrypted data without decrypting it.                                                    |
| [Zero-Knowledge Proofs (ZKP)](Zero-Knowledge%20Proofs.md)                | A cryptographic method that allows one party to prove the validity of a statement without revealing any underlying information. |
| [Trusted Execution Environments (TEE)](Trusted%20Execution%20Environment.md) | Ensures the integrity and confidentiality of computations and data in untrusted environments.                                   |
| [Secure Multi-Party Computation (SMPC)](Secure%20Multi-Party%20Computation.md) | Allows multiple parties to collaborate on computations while keeping their input data private.                                  |
